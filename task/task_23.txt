Task 23: Configure Initial Authentication Flows (Multi-language, Multi-provider)

Context:
Authentication is a critical part of user onboarding and security. Yaariyo must support authentication via email, mobile, and social providers, with onboarding available in all supported languages.

Acceptance Criteria:
- Users can register and log in using email, mobile, or social accounts.
- Onboarding and authentication flows are available in all supported languages.
- Authentication is secure and meets best practices.

Subtasks:
1. Implement authentication flows for email, mobile, and social providers.
2. Localize onboarding and authentication screens for all supported languages.
3. Integrate authentication with the database and user management system.
4. Test authentication flows for security, usability, and localization.
